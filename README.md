# Industrial Vision

Учебный программный модуль технического зрения для промышленного
мобильного роботизированного комплекса.
## Основные функции, которые должны быть реализованы

- Получение видеопотока.
- Детекция людей и транспорта.
- Контролируемые зоны ROI.
- Отслеживание объектов.
- Контроль средств индивидуальной защиты.
- Детекция дыма и огня.
- Исследовательская детекция разливов.
- Формирование и сохранение событий.
- REST API.
- Журналирование ошибок.
- Измерение производительности.

## Установка
Клонировать репозиторий;

Создать виртуальное окружение:

```powershell
python -m venv .venv
```
Установить зависимости:
```powershell
python -m pip install -r requirements.txt
```
